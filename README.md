# Banco_CodRestaurante

## Sobre o Projeto

Este repositório contém o código-fonte do projeto **Banco_CodRestaurante**.

O objetivo do projeto é desenvolver um sistema em Java utilizando JavaFX, aplicando conceitos de interface gráfica, organização em camadas e integração com banco de dados.

A estrutura principal do projeto está organizada nos seguintes diretórios:

- `VIEW`
- `CONTROLLER`
- `MODEL`
- `DAO`

---

## Tecnologias Utilizadas

- Java
- JavaFX
- Eclipse IDE

---

## Configuração do Projeto

Atualmente, para executar o projeto, é necessário:

1. Baixar e instalar o JavaFX
2. Configurar as bibliotecas do JavaFX dentro do Eclipse
3. Importar o repositório na IDE
4. Executar a aplicação normalmente

---

## Objetivo Acadêmico

O projeto foi desenvolvido com foco em estudos de:

- Programação Orientada a Objetos (POO)
- Estrutura MVC
- Integração com banco de dados
- Desenvolvimento de interfaces gráficas em Java
